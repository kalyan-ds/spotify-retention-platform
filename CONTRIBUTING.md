# Contributing to Spotify Premium Retention Intelligence Platform

Thank you for your interest in contributing to the Spotify Premium Retention Intelligence Platform!

---

## Development Workflow

1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Run `npm install` inside `frontend/` to install dependencies.
3. Ensure TypeScript compiles cleanly: `npm run build`.
4. Commit your changes following Conventional Commits (`feat: add new retention metric`).
5. Open a Pull Request referencing the related issue.
