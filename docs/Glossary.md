# Enterprise Technical Glossary - Version 2.0

- **Churn Probability**: Statistical likelihood (0.0 to 1.0) that a Spotify Premium subscriber will cancel their subscription within 30 days.
- **Next Best Action (NBA)**: Prescriptive AI intervention recommended to retain a high-risk subscriber.
- **Population Stability Index (PSI)**: Metric quantifying feature drift in machine learning models over time.
- **JWT (JSON Web Token)**: Standardized compact, URL-safe token used for stateless REST authentication.
- **RBAC (Role-Based Access Control)**: Authorization paradigm restricting system access to authorized user roles.
- **WCAG (Web Content Accessibility Guidelines)**: Standardized accessibility guidelines maintained by W3C.
