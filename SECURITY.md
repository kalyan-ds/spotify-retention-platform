# Security Policy & Vulnerability Disclosure

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 2.0.x | :white_check_mark: |
| < 2.0.0 | :x: |

---

## Reporting a Vulnerability

Please report security vulnerabilities to `security@spotify.com`. Do NOT open public GitHub issues for security vulnerabilities.
We respond to security disclosures within 24 hours and issue patch releases within 7 days.
